Pronto ✅

O front-end completo do InfoHub → InovAMF está no zip acima. Build testado (npm run build) e servidor de desenvolvimento validado sem erros.

Como executar localmente
bash
# 1. Extraia o zip e entre na pasta
cd infohub-inovamf

# 2. Instale as dependências
npm install

# 3. Rode o servidor de desenvolvimento
npm run dev

Acesse http://localhost:5173.
